# سامانه مدیریت مدرسه بشری — نسخه ۱.۵.۵

اپلیکیشن Android آفلاین‌اول برای مدیریت مدرسه (حضور و غیاب، نمرات، اعلان ایتا).

## قابلیت‌ها
- صفحه راه‌اندازی: نام مدرسه + لوگو
- ورود با آدرس سرور (اختیاری) + نام کاربری/رمز
- پنل معلم محدود به کلاس/درس اختصاص‌یافته
- تاریخ شمسی از ۱ مهر ۱۴۰۵ با سه کشوی روز/ماه/سال (۵ سال)
- سال تحصیلی و نوبت به‌صورت کشویی
- اعلان غیبت به والدین و مدیر از طریق ایتا
- کیبورد: صفحه اسکرول می‌شود و محتوا زیر کیبورد نمی‌ماند
- تم بنفش مرتب

## بیلد
با push به `main`، GitHub Actions APK امضاشده می‌سازد.

## نصب
فایل `Boshra-School-v1.5.5-release.apk` را نصب کنید (نسخه قبلی را حذف کنید).
