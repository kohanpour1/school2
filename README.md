# سامانه مدیریت مدرسه بشری — School 1.5.5 RC3

نسخه نامزد انتشار سامانه مدیریت مدرسه، شامل اپلیکیشن Android، سرور همگام‌سازی Node.js و صفحه فارسی اتصال موبایل به سرور محلی.

- نسخه: `1.5.5-rc3`
- شاخه اصلی: `main`
- راهنمای اجرا و تنظیمات: همین README و `server/README.md`
- وضعیت بررسی‌ها و محدودیت‌های بیلد: `BUILD_STATUS.md`
- گردش‌کار CI/CD: `.github/workflows/android-release.yml`

## اجرای محلی سرور
در پوشه `server` دستورهای `npm install` و سپس `npm start` را اجرا کنید. پورت پیش‌فرض `3847` است. فایل `start-server.bat` برای اجرای ویندوزی و نمایش صفحه اتصال فارسی در نظر گرفته شده است.

## بیلد خودکار
با push به شاخه `main`، GitHub Actions اعتبارسنجی، ساخت APK آزمایشی Android و ساخت فایل اجرایی Windows را اجرا می‌کند. برای APK انتشار امضاشده باید Secrets زیر در مخزن تعریف شوند: `KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS` و `KEY_PASSWORD`.

## نکات امنیتی
رمزهای پیش‌فرض را پیش از استفاده عملی تغییر دهید. توکن‌های سرویس‌ها را فقط از طریق تنظیمات امن یا متغیر محیطی وارد کنید و هیچ کلید خصوصی یا فایل keystore را در مخزن قرار ندهید.

این نسخه هنوز نامزد انتشار است؛ موفقیت کامل فقط پس از سبز شدن همه Jobهای Actions و آزمون نصب/اجرای عملی تأیید می‌شود.
